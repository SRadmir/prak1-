# 🐳 Docker-контейнер для Redis

> **Redis** — это высокопроизводительная база данных типа «ключ-значение» в оперативной памяти (in-memory), которая часто используется как кэш, брокер сообщений и хранилище сессий.

Данный Docker-образ предоставляет готовую к запуску среду Redis для разработки, тестирования и production-развертываний. Он основан на официальном образе [`redis:alpine`](https://hub.docker.com/_/redis), что обеспечивает минимальный размер и высокую безопасность.

---

## 📋 Поддерживаемые теги и аргументы образа

В таблице ниже перечислены ключевые параметры (аргументы), которые можно передать при запуске контейнера через команду `docker run`.

| Аргумент | Описание | Значение по умолчанию |
| :--- | :--- | :--- |
| `--restart` | Политика перезапуска контейнера при сбоях или перезагрузке хоста. | `no` |
| `-p`, `--publish` | Проброс портов с хоста в контейнер. | `6379:6379` |
| `-v`, `--volume` | Монтирование тома или директории хоста для сохранения данных Redis (RDB/AOF файлов). | Нет |
| `--name` | Присвоение понятного имени запущенному контейнеру. | Случайное имя (например, `gracious_mcclintock`) |
| `-d`, `--detach` | Запуск контейнера в фоновом режиме (демон). | Контейнер запускается в foreground |

> **Примечание:** Для **производственного использования** критически важно настроить **монтирование томов (`-v`)** для сохранности данных и политику **автоперезапуска (`--restart`)**.

## 🚀 Быстрый старт

Чтобы запустить контейнер Redis с настройками по умолчанию, выполните следующую команду:
```
bash
docker run -d \
  --name my-redis-cache \
  -p 6379:6379 \
  redis:alpine
```
### Пояснение команды:

```-d``` — запускает контейнер в фоновом режиме.

```--name my-redis-cache``` — присваивает контейнеру удобное имя.

```-p 6379:6379``` — пробрасывает порт 6379 из контейнера на порт 6379 вашего хоста.

```redis:alpine``` — указывает используемый Docker-образ.

### После запуска вы можете подключиться к Redis с вашей машины, используя redis-cli:
```
bash
redis-cli -h localhost -p 6379
```
## ⚙️ Настройка через переменные окружения
Контейнер Redis можно гибко настраивать с помощью переменных окружения. Они передаются через флаг ```-e``` в команде ```docker run```.

```REDIS_PASSWORD``` — устанавливает пароль для аутентификации в Redis. Настоятельно рекомендуется задавать в production!

> **Пример** : ```-e REDIS_PASSWORD=my_strong_password```

```REDIS_PORT``` — изменяет порт, на котором слушает Redis внутри контейнера. Не забудьте также изменить пробрасываемый порт с помощью ```-p```.

> **Пример** : -e REDIS_PORT=6380

```REDIS_appendonly``` — включает режим сохранения данных AOF (Append Only File) для большей durability.

> **Пример** : -e REDIS_appendonly=yes

### Пример запуска с настройками
Следующая команда запускает защищённый Redis с сохранением данных на хост-машине:
```
bash
docker run -d \
  --name my-production-redis \
  -p 6379:6379 \
  -v /path/on/host:/data \
  -e REDIS_PASSWORD=super_secret \
  -e REDIS_appendonly=yes \
  --restart unless-stopped \
  redis:alpine
```
## 🔧 Проверка работоспособности
Убедиться, что контейнер работает корректно, можно с помощью следующих команд:

Просмотр логов:
```
bash
docker logs my-redis-cache
```

Проверка состояния контейнера:
```
bash
docker ps --filter "name=my-redis-cache"
```
Выполнение команды внутри контейнера:
```
bash
docker exec -it my-redis-cache redis-cli ping
```
Ожидаемый ответ: PONG

## 🗂️ Структура данных и тома
Для сохранения данных между перезапусками контейнера необходимо смонтировать том. Внутри контейнера Redis по умолчанию хранит данные по пути /data. Укажите корректный путь на вашем хосте:
```
bash
-v /my/redis/data:/data
```
> **Важно**: Права на запись в директорию /my/redis/data должны быть у пользователя, от которого запущен процесс Redis внутри контейнера (обычно UID 1001).
